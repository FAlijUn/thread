### 并发cocurrency/多线程multithreading
多核处理器，硬件并发

单核任务切换
  任务从一个任务切换到另一个任务需要进行一次上下文切换(context switch)
  任务切换存在时间开销
  进行上下文切换时操作系统为当前运行的任务保存CPU状态和指令指针，并计算出需要切换到哪个任务
  为即将切换的任务重新加载处理器状态
  CPU将新的任务的指令的数据的内存载入到缓存中，会阻止CPU执行任何指令，造成更多的延迟

多进程并发
  独立的进程间可以通过(信号，套接字，文件，管道)进行信息的传递
  操作系统会在进程间通信采取一定的保护措施，以避免一个进程修改另一个进程的数据，导致时间开销增加
  使用独立的进程可以使用远程连接，在不同机器上运行独立的进程

多线程并发
  在单个进程中运行多个线程
  进程中所有的线程都由共享地址空间
  数据要被多个线程访问，需要确保每个线程所访问到的数据是一致的

线程是有限的资源，多个线程同时运行消耗很多的资源
每一个线程都需要一个独立的堆栈空间，运行太多线程会耗尽进程的可用内存和地址空间
线程池可以用来限制线程的数量
运行越多的线程，操作系统就需要做越多的上下文切换

原子操作库，可以用于直接控制单个位、字节、内部线程间同步
